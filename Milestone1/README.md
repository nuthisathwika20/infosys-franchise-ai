# Infosys Springboard Internship 7.0 - Milestone 1

## User Authentication Module

### Project Overview

Milestone 1 focuses on building a user authentication application using Streamlit. The application will allow users to create accounts,login securely,recover forgotten passwords,and access a dashboard after successful authetication.

### Features
- User registration with username,email,password, and security question.
- Login with username/email and password.
- Input validation fpr required fields,email format,and password strength.
- JWT-based session authentication.
- Forgot password using a security question or email OTP.
- User dashboard with a welcome message and logout functionality.
- Admin login and dashboard to view registered usernames and email addresses.
- Sending OTP throgouh Gmail.
- Public access to application through an ngrok.

### Technology Stack

### Configuration
The application uses environment variables for email and JWT configuration.

Configure the following secrets in Google Colab:
- **EMAIL_ADDRESS** — Gmail address used to send OTP emails.
- **EMAIL_PASSWORD** — Gmail App Password used for SMTP authentication.
- **JWT_SECRET** — A strong, randomly generated secret key.
- **NGROK_AUTHTOKEN** — Authentication token used to create the public ngrok UR

### How to Run

1. Open authentication_module.ipynb in Google Colab.
2. Configure the required secrets in Colab.
3. Install the required Python packages if they are not already installed.
4. Run the notebook cells in the correct order.
5. Start the Streamlit application using the provided launcher cell.
6. Open the public application URL generated by ngrok.
7. Test registration, login, password recovery, logout, and administrator functionality.
